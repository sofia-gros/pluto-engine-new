# `pluto-perf` スキル

このスキルは、エンジンの中核となるHOTパス（毎フレーム実行されるコード）を編集した場合や、10万〜100万スプライト144FPSの目標に直結する変更を行った際に使用します。

## 手順

1. **ベンチマークの実行**
   - 実装後、`pnpm bench` （または該当するパフォーマンステストコマンド）を実行します。
2. **結果の分析**
   - 実行結果の数値を記録し、変更前のベースライン（もしあれば）と比較します。
   - フレームタイム（ms）やスループットを確認し、1フレームの予算（6.94ms）に収まっているか、または特定のサブシステムの予算（CPU: 2.0ms, GPU: 2.0ms, 描画: 2.5ms）に収まっているかを確認します。
3. **悪化の判定**
   - ベースラインから10%以上の性能悪化が見られる場合は **不合格** です。
   - 不合格の場合は `pluto-implement` に戻り、プロファイリング結果（推測されるボトルネック）に基づいて最適化を行います。オブジェクトの生成や不要なループがないか、R2ルールを再確認してください。
4. **記録**
   - パフォーマンスが要件を満たした場合、そのベンチマーク結果を `pluto-review` での自己レビュー記録に含めてください。
