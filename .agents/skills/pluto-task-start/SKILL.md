# `pluto-task-start` スキル

このスキルは、新しいタスクを開始する際に **必ず最初** に実行してください。

## 手順

1. **現在の状態の確認**
   - `docs/progress/PROGRESS.md` を読み、現在着手すべきタスクID（例: T-0.1）を特定します。
2. **ロードマップの確認**
   - `docs/12-roadmap.md` を開き、特定したタスクIDの「目的」「作業内容」「参照ドキュメント」「受け入れ条件」を読み込みます。
3. **関連ドキュメントの熟読**
   - ロードマップに記載されている「参照ドキュメント」をすべて読み込みます。
   - `docs/02-directory-structure.md` を確認し、作成・編集すべきファイルのパスと責務を特定します。勝手に新しいディレクトリを作ってはいけません。
4. **実装計画の作成**
   - `docs/progress/current-task.md` を作成（または上書き）し、以下の内容を記述します。
     - タスクIDと名前
     - 目的
     - 編集・作成するファイルのリスト（`02-directory-structure.md` と完全に一致させること）
     - 実装ステップ（テスト作成を含む）
     - 完了条件（受け入れ条件のコピー）
5. **完了**
   - 計画が完成したら、ユーザーに計画の概要を報告し、次の `pluto-implement` スキルへ進む準備ができていることを伝えます。
