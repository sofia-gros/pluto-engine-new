# `pluto-shader` スキル

このスキルは、WebGPU (`.wgsl`) や WebGL2 (`.glsl`) のシェーダファイル、およびGPUバッファレイアウトに関連するコードを編集する際に使用します。

## 手順

1. **R4 ルールの確認**
   - `.agents/rules/04-shaders.md` の内容を熟読し、シェーダ作成のガイドラインを確認します。
2. **レイアウトの厳密な計算**
   - GPUバッファ（Uniform, Storage）のメモリレイアウトは、アライメント（std140, std430）を厳密に計算し、TypeScript側の TypedArray と完全に一致させます。
   - 変更がある場合は、TypeScriptの構造体定義とシェーダの構造体定義のズレがないかを入念にチェックします。
3. **バックエンド互換性の考慮**
   - WebGPU と WebGL2 の両方で動作するように設計されているか確認します（Pluto EngineはWebGPU優先、WebGL2フォールバックの要件があります）。
4. **テストの考慮**
   - シェーダのロジックをテストするための手段（コンピュートシェーダによるテストや、CPU側でのエミュレーションテストなど）が提供されているか確認し、検証します。
