# `pluto-task-finish` スキル

このスキルは、タスクの最終完了処理を行うためのスキルです。`pluto-review` が成功した後にのみ実行します。

## 手順

1. **Definition of Done (DoD) の最終確認**
   - `AGENTS.md` の「5. 完了の定義」をすべて満たしているか最終確認します。
     - `pnpm verify` エラー/警告 0
     - 受け入れ条件の網羅
     - テストの存在
     - JSDoc日本語化
     - レビュー記録 (`docs/progress/reviews/T-x.y.md`) の存在
2. **PROGRESSの更新**
   - `docs/progress/PROGRESS.md` を開き、現在のタスクのステータスを `[x]` に変更します。
   - 次に着手すべきタスクがあれば、それを「現在のタスク」としてマークします。
3. **ユーザーへの報告**
   - タスクが完了したことをユーザーに報告し、次の指示を仰ぎます。
   - （※実際のGitコミットは、ユーザーの環境や指示に依存するため、実行する前にユーザーに「コミットしてよいか」確認を取ることが推奨されます。無断でのコミットや履歴改変は禁止されています。）
