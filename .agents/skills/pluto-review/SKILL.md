# `pluto-review` スキル

このスキルは、テスト通過後に、コードがPluto Engineの厳格な規約にすべて従っているかを最終確認するためのスキルです。

## レビューチェックリスト

以下の全項目をチェックしてください。

- [ ] `AGENTS.md` の「3. 絶対禁止事項」を1つも破っていないか？
- [ ] `docs/02-directory-structure.md` に記載されていない無断のファイル追加はないか？
- [ ] R1: すべての関数・メソッドに型の明示があるか？ `any` などの禁止された型を使っていないか？
- [ ] R1: JSDocのコメントはすべて日本語で記述されているか？
- [ ] R2: HOTファイル（`// @pluto-hot`）内で、メモリ確保や配列高階関数などの禁止操作を行っていないか？
- [ ] R3: アーキテクチャ境界を破るimport（他モジュールの内部ファイルを直接importするなど）はないか？
- [ ] すべてのテストが `pnpm verify` および `pnpm test` をパスしているか？
- [ ] `docs/12-roadmap.md` に記載されたタスクの「受け入れ条件」を100%満たしているか？

## 手順

1. 上記のチェックリストを自己評価します。
2. レビュー結果を `docs/progress/reviews/T-x.y.md` (x.yはタスクID) としてマークダウンファイルに書き出します。
3. 問題が見つかった場合は、直ちに `pluto-implement` に戻って修正してください。
4. すべてOKであれば、レビューファイルを作成した旨をユーザーに報告します。
