# `pluto-test` スキル

このスキルは、実装が完了したコードの品質を担保し、エラーがないことを確認するためのスキルです。

## 手順

1. **静的解析と型チェックの実行**
   - `pnpm verify` コマンドを実行します（Lint, フォーマット, 型チェックなどが含まれます）。
   - エラーまたは警告が出た場合、すべて修正してください。警告を無視したり、ルールを無効化（`eslint-disable` や `@ts-ignore` など）してはいけません。
2. **ユニットテストの実行**
   - `pnpm test` （または該当ファイルの個別テスト）を実行します。
   - すべてのテストがパスすることを確認します。
   - テストが失敗した場合、実装またはテストコードを修正して再実行します。テスト自体を削除したり、スキップ（`.skip`）したりしてごまかすことは禁止されています。
3. **カバレッジの確認**
   - 必要に応じて `pnpm test:coverage` を実行し、十分なカバレッジがあるか確認します。
4. **アーキテクチャ境界チェック**
   - （ツールが用意されている場合）`node tools/check-boundaries.mjs` などを実行し、依存関係のルール違反がないか確認します。
5. **報告**
   - すべてのチェックが通過したら、コマンドの出力要約をユーザーに報告します。
