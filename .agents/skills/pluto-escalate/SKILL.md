# `pluto-escalate` スキル

このスキルは、エージェント自身で判断してはいけない状況（停止ルール）に遭遇した際に **直ちに作業を止めて** 実行するスキルです。

## 発動条件（以下のいずれかに該当した場合）

- ドキュメント同士が矛盾している、またはドキュメントに記載がない設計判断が必要になった。
- 同じエラーを **3回** 修正しようとして直らない（3ストライクルール）。
- タスクの完了条件を満たす方法が分からない。
- 性能目標をどうしても満たせない。
- 既存のテストを壊さないと先に進めない（仕様変更の疑い）。
- ブラウザAPIの仕様が不明で、憶測でコードを書かざるを得ない。

## 手順

1. **作業の停止**
   - 現在の実装や修正作業を即座に停止します。勝手な推測で進めてはいけません。
2. **記録の作成**
   - `docs/progress/escalations.md` ファイルに以下のフォーマットで追記します。
     - 日時:
     - 発生している問題の概要:
     - 試行したこと（証拠・コマンド出力・エラー内容など）:
     - 不明点・ユーザーへの質問事項:
3. **ユーザーへの報告**
   - ユーザーに対して日本語で「作業を停止した理由」「やったこと」「証拠となる出力」「未解決事項・質問」を簡潔に報告し、明確な指示を待ちます。
