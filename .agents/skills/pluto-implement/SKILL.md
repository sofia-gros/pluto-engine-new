# `pluto-implement` スキル

このスキルは、`pluto-task-start` で作成した計画に従ってコードを記述するためのスキルです。

## 手順

1. **計画の確認**
   - `docs/progress/current-task.md` を読み、現在のステップを確認します。
2. **テストの作成 (TDD)**
   - 実装対象のコードに対するユニットテストを先に記述します。
   - テストファイルは `tests/unit/` 以下の対応するディレクトリに作成します。
3. **コードの実装**
   - テストを通すためのコードを記述します。
   - 常に `AGENTS.md` の絶対禁止事項と、`.agents/rules/` にあるルール（特に R1 コーディングルール）を遵守してください。
   - JSDocによる日本語コメントをすべての公開シンボルに付与してください。
4. **HOTパスのチェック**
   - 編集しているファイルが `docs/02-directory-structure.md` で `HOT` と指定されている場合、必ずファイルの1行目に `// @pluto-hot` を記述し、R2 パフォーマンスルールを厳格に適用してください。
5. **アーキテクチャ境界の遵守**
   - import文は必ず R3 アーキテクチャ境界ルールに従ってください。
   - 他モジュールの内部ファイルを直接importせず、必ず `index.ts` を経由してください。

## 制限事項

- タスク外のコード（ついでに直すなど）は絶対に記述しないでください。
- 依存パッケージを勝手に追加しないでください。
