| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| 記述子型 | `BufferDesc`, `TextureDesc`, `SamplerDesc`, `BindGroupLayoutDesc`, `BindGroupLayoutEntryDesc`, `BindGroupEntryDesc`, `BindGroupDesc`, `ColorTargetDesc`, `DepthStencilDesc`, `RenderPipelineDesc`, `ComputePipelineDesc`, `TextureWriteDesc`, `ColorAttachmentDesc`, `RenderPassDesc` | `docs/06` §5.1 |

- `docs/02` §12 の `src/rhi/device.ts` の責務一覧に `RhiBindGroupLayout` と `RhiQuerySet` が無かった (`docs/06` §4 は要求していた)。
- `docs/06` §5 の定数表に **テクスチャ用途を表す定数が無かった**。`TextureDesc` が用途を从哪里 持つか不定だったため、WebGPU の `GPUTextureUsage` と同じ 5 種を追加した。番号は `CopySrc: 1, CopyDst: 2, TextureBinding: 4, RenderAttachment: 8, StorageBinding: 16` と他のビットフラグに合わせて 2 の冪にした。

決定事項は `docs/12` の **D-21**、経緯は `docs/progress/escalations.md` の **E-003** に記録した。

### ミップマップを持たないという判断

`docs/07` のアトラス規格が「KTX2 はミップはレベル 0 のみ使用」なので、`TextureDesc` に `mipLevelCount` を **入れなかった**。サンプラも `FilterMode` 2 種だけで `mipmapFilter` を持たない。これを入れると WebGL2 側で常に無効分岐を持つことになり、実効がないため。

## 設計上の判断

### 頂点バッファ API を持たない

`docs/06` §4 の注記どおり `createVertexBuffer` 系は持たない。四角形は `draw(6, instanceCount)` で `vertex_index` から生成する。

### 頂点シェーダとフラグメントシェーダを `RenderPipelineDesc` に分ける

WebGPU の `GPURenderPipelineDescriptor` は `vertex` と `fragment` の 2 フィールドで別々のモジュールを持つ。RHI も同じ形にした。`ComputePipelineDesc` は 1 本だけ。

### `ShaderSource` を単一オブジェクトにまとめる

WebGPU は `GPUShaderModule` (WGSL のみ)、WebGL2 は `glVertexShader` と `glFragmentShader` の別々。`docs/06` §6 の定義どおり両方を 1 つの型に持たせ、バックエンドが必要とする方を読む。

### `BindGroupEntryDesc` はレイアウトの添字で紐づける

WebGPU の `GPUBindGroupEntry` と同じ方式。`layout` 側の `entries[i]` と `entries[i]` の `type` が一致することを §5.1.1 の検証規則で強制する。

## 検証規則の実装は T-3.2 / T-3.3 の責務

`docs/06` §5.1.1 の 17 個の検証規則は **`create*` を実装するバックエンド側**で行う。T-3.1 はインターフェースと型だけなので、検証コードは置いていない。検証コードを置くファイル名も `docs/02` §12 に無い (`types.ts` は「定数と記述子型」、`device.ts` は「インターフェース」)。

**T-3.2 (WebGPU) と T-3.3 (WebGL2) は §5.1.1 の全規則を両バックエンドで実装すること。** 共通のヘルパ置き場が無いので、必要なら `docs/02` §12 への追記をユーザー指示で 얻ること。

## D-22: 旧規格との不一致を正したこと (2026-10-07)

### 前提: テストの中で WebGPU 規格と異なったことが 3 件あった

テストの従来、`src/rhi/validate.ts` の検証ルールを作る前に `docs/06` §5.1.1 の規則を WebGPU エダードドラフト (2026-09-23) と照合した。**初版の規則 3 件が WebGPU 規格と逆っていた。**

| 初版の規則                               | WebGPU の規格                                                | 不合                  |
| ---------------------------------------- | ------------------------------------------------------------ | --------------------- |
| `MapRead` と他のビットを同時に指定しない | `MAP_READ` を含む場合、`COPY_DST` 以外のフラグは指定できない | 可能性を殈していた    |
| `offsetBytes` は 256 の倍数              | `limits.minUniformBufferOffsetAlignment` の倍数              | 固定値                |
| `workgroupSize` の経は 1024 以下         | `limits.maxComputeInvocationsPerWorkgroup` (既定 256)        | 1024 という定数は無く |

第 1 行は特に危険で、このままの規則では `readBufferAsync` に必要な `MAP_READ | COPY_DST` を作れなかった。

### 修正内容

| 判断         | 内容                                                                                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 判断1        | `RhiCapabilities` に `maxComputeInvocationsPerWorkgroup` ・`minUniformBufferOffsetAlignment` ・`minStorageBufferOffsetAlignment` の 3 つを追加 (14 → 17 プロパティ) |
| 判断2        | 検証ルールを `src/rhi/validate.ts` に集約し、`docs/02` §12 に行を追加                                                                                               |
| 判断3        | スワップチェーンの format を `SWAPCHAIN_FORMAT` (= `bgra8unorm`) に固定                                                                                             |
| 判断4        | `storage-emulation.glsl` の関数名を `docs/06` §7 に合わせて `pluto_fetch` に統一 (`docs/02` §15 を修正)                                                             |
| 判断5        | `DATA_TEXTURE_WIDTH` と `DATA_TEXTURE_TEXEL_BYTES` を `src/rhi/types.ts` の定数に追加                                                                               |
| 判断6 (追加) | `RGBA16Float` は `caps.floatRenderTarget` が false なら `UnsupportedFeature`、`RGBA32Float` のブレンドは `caps.floatBlend` で判定                                   |

**判断4 についての補正**: `docs/02` §15 は同じファンクションを「WebGL2 データテクスチャ読取ヘルブ (`fetchU32x4(index)` 等)」と書い、`docs/06` §7 は `pluto_fetch(tex, texelIndex)` と書いていた。同じものを指していたので同じ権かた。
