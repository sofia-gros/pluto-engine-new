# ADR-0002: 2D 専用

- 状態: 確定
- 日付: 2026-10-05

## 背景

将来の 2.5D / 3D 拡張を考慮するかどうか。

## 決定

2D 専用とする。3D への拡張性は考慮しない。

## 理由

- 2D に特化することで、データレイアウト (32 バイトインスタンス)、カリング (2D 矩形)、ソート (layer + sortKey) を最小・最速にできる。
- 汎用性のための抽象化コストを払わない。

## 影響

- mat4、透視投影、3D メッシュ、3D 物理を実装してはならない。
- 深度バッファは描画順 (layer) の表現と early-z のためだけに使う。

## 却下した代替案

- 2.5D (アイソメトリック等の疑似 3D) を前提にする → layer/sortKey で表現可能なので不要。
