# ADR-0006: 単一パッケージ + 厳格なレイヤー

- 状態: 確定
- 日付: 2026-10-05

## 背景

モノレポ (複数パッケージ) と単一パッケージのどちらにするか。

## 決定

単一 npm パッケージ `pluto-engine` とし、`src/` 内をモジュール (ディレクトリ) に分割する。モジュール間の依存は許可表で厳格に制限し、`tools/check-boundaries.mjs` で機械的に検査する。

## 理由

- ビルド・テスト・2 ビルド構成が単純になる。
- ツリーシェイクが効きやすい。
- AI エージェントが迷う余地 (どのパッケージに置くか、パッケージ間のバージョン) を減らす。

## 影響

- 他モジュールの import は必ず `index.ts` 経由。
- ファイルの追加は `docs/02-directory-structure.md` に記載されたものに限る。

## 却下した代替案

- pnpm workspaces によるモノレポ → 設定・公開の複雑さに見合う利点がないため却下。
