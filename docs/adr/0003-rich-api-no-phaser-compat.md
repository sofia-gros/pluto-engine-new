# ADR-0003: Phaser 互換なし・全機能を高レベル API で提供
- 状態: 確定
- 日付: 2026-10-05

## 背景
Phaser は「1 万行のコードが 5 行で済む」ほど高レベル API が充実している。この体験は欲しいが、Phaser の API 形状 (1 オブジェクト = 1 GameObject) は SoA / GPU 駆動と相性が悪い。

## 決定
- Phaser との API 互換は目指さない。
- ただし **エンジンが持つすべての機能を高レベル API (`scene.*`) から数行で使えるようにする**。
- 内部構造 (ECS, RHI 等) は `pluto-engine/lowlevel` として上級者に公開する。

## 理由
- 互換性に縛られず、SoA と矛盾しない API (薄いハンドル、一括 API、GPU Tier ハンドル) を設計できる。
- 機能があっても使うのが難しければ価値が出ないため、高レベル入口を必須とする。

## 影響
- 下位層に機能を追加するタスクは、高レベル API とサンプルまで含めて完了 (`docs/09-api-design.md` A1)。
- 高レベル API はホットパスのロジックを持たない (下位層に委譲)。

## 却下した代替案
- Phaser 互換レイヤー → 1 オブジェクト 1 GameObject を強制され性能目標と両立しないため却下。
